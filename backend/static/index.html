Raw vinyl position written as TRACKNUMBER (e.g. A1, B1). Default behaviour.

DISCNUMBER per physical record, TRACKNUMBER sequential across both sides + VINYLPOSITION tag. Single LPs appear as 1 disc. Correct sort order in Jellyfin, Roon, Plex.

24-bit keeps full precision after processing and album gain but makes files larger; some older players only support 16-bit.

Same setting as the Audio processing panel. Stronger settings catch fainter clicks but take longer to process.

Removes mains hum (50/60 Hz and harmonics). The Audio processing panel suggests it when a file has hum.

Use only if you hear hum. It cuts narrow notches at 60, 120 … 360 Hz, which can quiet bass notes close to those frequencies (by up to several dB). Check bass-heavy records with the test in the Audio processing panel.

Same setting as the Audio processing panel. Stronger settings take out more hiss but can soften very quiet cymbals and room ambience.
